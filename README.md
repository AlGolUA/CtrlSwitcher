# README.md

## CtrlSwitcher.exe

**CtrlSwitcher.exe** — это скомпилированная из скрипта `CtrlSwitcher.ahk` для AutoHotkey (v2.0) утилита, предназначенный для упрощения переключения языков, отображения текущего языка, авто-замены слов и транскрипций текста.

### Основные функции

1. **Управление языками**:
    - Переключение между английским, русским и украинским раскладками одним нажатием клавиши.
    - Улучшенное отображение текущего активного языка.

2. **Транскрипция текста**:
    - Транскрипция выделенного или введенного текста между английским и русским.

3. **Автозамена**:
    - Автозамена вводимых слов на предустановленные слова/фразы. Например, замена "щл" на "OK".

4. **Динамические индикаторы**:
    - Возможность настройки индикаторов текущего языка - рамки вокруг экрана и/или текстового индикатора.

5. **Настройки**:
    - Настройка через файл `.ini`, включающая возможность включения/отключения функций, настройку исключенных приложений и определение пользовательских автозаменяемых слов.

### Установка и настройка

1. **Скачивание и сохранение**:
    1. Вариант 1.
        - Скачайте утилиту `CtrlSwitcher.exe`.
        - Перенесите её в нужный каталог. Если понравится утилита - создайте ярлык и добавьте в автозапуск.
    2. Вариант 2.
        - Установите утилиту AutoHotkey (v2.0)
        - Скачайте скрипт `CtrlSwitcher.ahk`.
        - Сохраните его в нужный каталог.

2. **Запуск**:
    1. Вариант 1.
        - Выполните двойной щелчок на файле `CtrlSwitcher.exe`, чтобы запустить его.
    2. Вариант 2.
        - Если AutoHotkey установлен, то запустите скрипт двойным щелчком на файле `CtrlSwitcher.ahk`.

При первом запуске создастся файл settings.ini с настройками по умолчанию. Далее его можно настроить "под себя".

### Файл настроек (settings.ini)

Скрипт использует файл `.ini` для хранения пользовательских настроек. Вы можете отредактировать этот файл для настройки поведения скрипта под ваши нужды. Вот некоторые настраиваемые параметры:

- **Первоначальное включение/отключение звуковых функций**:
```ini
[General]
      EnableSound=true
```


- **Параметры рамки и текстового индикатора**:
```ini
[General]
      IndicatorSize=2
      BorderThickness=3
      BorderSides=NESW
```

- **IndicatorSize**:
    - `0`: Индикатор отключен.
    - `1`: Маленький индикатор.
    - `2`: Средний индикатор.
    - `3`: Большой индикатор.
    - `4`: Очень большой индикатор.

- **BorderThickness**:
    - `0`: Нет рамки.
    - `1`: Тонкая рамка.
    - `2`: Средняя рамка.
    - `3`: Толстая рамка.
    - `4`: Очень толстая рамка.

- **BorderSides**:
    - `N`: Верхняя рамка.
    - `E`: Правая рамка.
    - `S`: Нижняя рамка.
    - `W`: Левая рамка.
    - Комбинации сторон могут быть объединены, например, `NESW` для всех сторон.


- **Исключенные и особые приложения**:
```ini
[General]
      ExcludeApps=cs.exe,mstsc.exe
      NoSystemLayoutApps=teams.exe,m365copilot.exe
```
**ExcludeApps**:
- Список приложений, где функциональность скрипта не используется.

**NoSystemLayoutApps**:
- Список приложений в которых API GetKeyboardLayout выдаёт неправильные результаты (как правило WebView приложения).

- **Цвета**:
```ini
[Colors]
      English=0
      Russian=0xDA291C
      Ukrainian=0x0057B8
```

Цвет рамки и текстового инидикатора для соответствующего языка. Если указан 0, то индикация соответствующего языка не отображается.

- **Звуки**:
```ini
[Sounds]
      EnglishSwitch=Sounds\en.wav
      RussianSwitch=Sounds\ru.wav
      UkrainianSwitch=Sounds\ua.wav
      EnglishKey=Sounds\en.wav
      RussianKey=Sounds\ru.wav
      UkrainianKey=Sounds\ua.wav
```
Позволяет определить проигрываемые wav файлы при переключении и нажатии клавиш букв соответствующего языка. Если значение не указано, то звук не проигрывается.
Можно указывать как абсолютный, так и относительный (по отношению к файлу приложения) путь к wav файлу.

- **Горячие слова**:

```ini
[Hotstrings]
      щл=OK
```

Позволяет указать автозаменяемые слова и текст их замен. В замещающем тексте можно указать \r и \n для переноса строк.

### Использование

1. **Переключение языков**:
    - Используйте `Left Ctrl` для переключения между английским и русским раскладками.
    - Используйте `Right Ctrl` для переключения между украинским и английским раскладками.

2. **Транскрипция текста**:
    - Выделите текст и нажмите `Pause`, чтобы транскриптировать его между английским и русским.
    - Если текст не выбран, то при нажатии `Pause` будет обработано последнее введенное слово.

3. **Логирование**:
    - Нажмите `Ctrl + Alt + Shift + L`, чтобы переключить логирование. Лог пишется в файл `script.log` в каталоге утилиты. Это может быть полезно для отладки или определения приложения для исключений или отслеживания транслитерации и изменений языка ввода.

4. **Включение/отключение звука**:
    - `Ctrl + Alt + Shift + S`: Позволяет включить/отключить звуковые функции.
